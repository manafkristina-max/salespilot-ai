# Demo Script — 5 минут

Подготовка: `./start.sh`, открыть http://127.0.0.1:8000. Для «чистого» демо остановите сервер и удалите `data/salespilot.db` (база создастся заново пустой). Если нужно сразу показать заполненный продукт, запустите `./start.sh --demo`.

## 0:00 — Контекст (30 с)
Dashboard в пустом состоянии. «SalesPilot помогает SDR-команде, продающей Rich Content / Where-to-Buy / PIM брендам, пройти путь от ICP до одобренного письма. Плашка Demo mode — честная граница: компании вымышлены, отправки симулируются, реальные метрики считаются отдельно».

## 0:30 — Кампания и ICP (45 с)
«Создать кампанию» → показать ICP: отрасли, география, тип компании, диапазон сотрудников и SKU, ключевые боли, продукт «Авто». Создать.

## 1:15 — Scout + агенты (45 с)
«Scout: демо-датасет» → 13 компаний из 14 подходят по ICP (одна отсеяна). «Запустить агентов» → тост: исследовано 13, квалифицировано 5, черновиков 5. Таблица отсортирована по ICP Fit; у части лидов «Не подходит».

## 2:00 — Объяснимый скоринг (60 с)
Открыть **Lumio Electronics**: 5 факторов с баллами и текстовым объяснением, уверенность, «Недостающие данные: контактное лицо». Блок Sales Agent: почему рекомендован продукт. Факты — каждый со ссылкой, датой проверки и статусом «Демо-источник». Подчеркнуть: контактов нет, система их не придумывает.
Затем открыть **Velora Fashion** (score ~70, но «Не подходит»): стоп-критерий «отрасль Fashion вне ICP».

## 3:00 — Письмо и согласование (75 с)
Outreach → письмо Lumio. Показать предупреждения, «Проверяемые утверждения» [1], [2] со ссылками. Поправить фразу → «Сохранить» → история v2. «Одобрить» → панель «Готовность к отправке» перечисляет, почему реальная отправка невозможна. «Симулировать отправку» → диалог явно говорит, что ничего не отправится. Вставить ответ «Интересно, давайте созвонимся» → Reply Handler: «Интерес, 95%».
Опционально: отредактировать одобренное письмо другого лида → статус возвращается в Needs Review.

## 4:15 — Аналитика и настройки (45 с)
Analytics: переключить «Реальные» — всё по нулям, и это правильно. «Все» — воронка с конверсиями, распределение score, таблица кампании с колонками «реал./сим.». Экспорт CSV.
Настройки: веса факторов и порог, заблокированное ручное одобрение, kill switch, статусы интеграций (что mock, что не подключено), логи агентов.

## 5:00 — Итог
«Это рабочий MVP: данные в SQLite переживают перезапуск, 20 автотестов. Для production нужны источник компаний, почтовый ящик для ответов, аутентификация и юридическая проверка — это в CASE_STUDY.md».
